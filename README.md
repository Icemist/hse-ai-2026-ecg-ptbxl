## 📋 О проекте

**О задаче** Одна запись ЭКГ может одновременно содержать признаки нескольких патологий, поэтому это мультиметочная классификация. Цель: модель, которая по 12-канальному сигналу ЭКГ определяет наличие различных сердечных патологий.

**Что понадобится** Основы ML/DL, модели классификации, основы обработки временных рядов и сигналов, метрики качества классификации, Python.

**Работа с данными**
- предобработка и фильтрация сигналов ЭКГ 
- анализ частоты встречаемости диагнозов • исследование дисбаланса классов 
- визуализация ЭКГ разных диагностических групп 
- временно-частотные представления сигналов 
- зависимость качества модели от числа используемых каналов

**ML / DL** 
- классификатор на статистических и спектральных признаках 
- одномерные свёрточные сети 
- сравнение: исходный сигнал против спектрограмм 
- мультиметочная классификация патологий 
- методы балансировки данных 
- подбор функций потерь под несбалансированную мультиметку 
- калибровка вероятностей модели 
- поиск участков сигнала, сильнее всего влияющих на прогноз

## 📊 Данные

[**PTB-XL**](https://physionet.org/content/ptb-xl/): открытый датасет клинических ЭКГ (PhysioNet, лицензия CC BY 4.0):

- 21 799 записей от 18 869 пациентов, по 10 секунд, 12 отведений;
- частота дискретизации 500 Гц и прореженная версия 100 Гц;
- разметка по стандарту SCP-ECG: 71 диагностическое утверждение, сведённое в 5 суперклассов;
- готовое стратифицированное разбиение на 10 фолдов, фолды 9 и 10 рекомендованы авторами как валидация и тест.

| Суперкласс | Значение | Записей |
|---|---|---:|
| NORM | нормальная ЭКГ | 9 514 |
| MI | инфаркт миокарда | 5 469 |
| STTC | изменения сегмента ST и зубца T | 5 235 |
| CD | нарушения проводимости | 4 898 |
| HYP | гипертрофия | 2 649 |

Сумма больше числа записей: у одной ЭКГ бывает несколько суперклассов сразу.

## 🎯 Метрики

- **macro ROC-AUC**: основная метрика, как в опубликованных бенчмарках на PTB-XL (Strodthoff et al., 2021);
- F1 и PR-AUC по каждому классу, из-за дисбаланса;
- ECE и диаграммы надёжности, для оценки калибровки вероятностей.

## 🚀 Запуск

Рабочее окружение: Linux, в Windows через WSL2; альтернатива Docker, образ в `Dockerfile`. Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/). Дальше две команды:

```bash
uv sync                                   # окружение и зависимости по uv.lock
uv run python scripts/download_ptbxl.py   # PTB-XL 1.0.3 -> data/raw/ptb-xl, ~3 ГБ на диске
```

Подробно, включая проверки и ноутбуки: [docs/setup.md](docs/setup.md).
