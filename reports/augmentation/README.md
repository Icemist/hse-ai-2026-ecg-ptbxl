# Аугментации ЭКГ - чекпоинт 2

В [общем EDA.ipynb](../../notebooks/EDA.ipynb) (раздел 5) сравниваются добавление шума, изменение амплитуды, дрейф изолинии и временной сдвиг. Графики и таблицы уже сохранены в ноутбуке. Исходная отдельная работа сохранена в [augmentation.ipynb](../../notebooks/augmentation.ipynb).

Модуль `src/ecg_ptbxl/augmentation_data.py` выбирает записи и скачивает сигналы; `src/ecg_ptbxl/augmentations.py` реализует преобразования.

## Данные и сравнение

- PTB-XL 1.0.3, `records100`: 100 Гц, 10 секунд, 12 отведений, mV.
- 175 пациентов из фолдов 1–8: по 25 записей с единственной меткой NORM/MI/STTC/CD/HYP и 50 мультиметочных. Seed 146.
- Метки берутся из `ptbxl_database.csv` и справочника `scp_statements.csv`. Учитывается наличие диагностического кода, включая likelihood 0. Записи без выбранных меток исключаются из выборки.
- У каждого метода три уровня силы - всего 2100 вариантов. Для одной записи случайная реализация остаётся той же на всех уровнях.

| Метод | Уровни | Результат |
|---|---|---|
| Гауссов шум | Опорный SNR 30 / 20 / 10 dB | Медианный NRMSE вырос с 0,033 до 0,329. При 10 dB медианное увеличение среднего \|diff\| - 113,5% |
| Изменение амплитуды | ±5 / ±15 / ±30% | Корреляция осталась равной 1, хотя амплитудные признаки изменились на выбранный процент |
| Дрейф изолинии | Медианная пиковая амплитуда 0,1 / 0,3 / 0,6 опорного RMS, 0,3 Гц | Медианный NRMSE вырос с 0,095 до 0,570. Среднее \|diff\| слабо реагирует на дрейф |
| Временной сдвиг | ±0,10 / ±0,25 / ±0,50 с | После выравнивания общей области ошибка равна 0, но теряются 1 / 2,5 / 5% исходных отсчётов |

Здесь сравниваются изменения сигналов.

## Запуск

Из корня репозитория:

```bash
uv sync --locked
uv run python scripts/download_augmentation_subset.py
uv run jupyter nbconvert --to notebook --execute --inplace notebooks/augmentation.ipynb --ExecutePreprocessor.timeout=300
```

Можно также открыть ноутбук через `uv run jupyter lab` и выполнить все ячейки. Загрузчик скачивает выбранные записи в `data/augmentation_ptbxl_1.0.3/` с [зеркала PhysioNet в AWS](https://registry.opendata.aws/ptb-xl/). Для основного сервера есть параметр `--base-url https://physionet.org/files/ptb-xl/1.0.3/`.

## Сохранённые результаты

- `sample_manifest.csv` - идентификаторы, фолды, группы и метки выбранных записей.
- `environment.json` - версии Python/пакетов, источник и SHA256 метаданных.
- `metrics.csv` - 2100 индивидуальных измерений; `realized_snr_db` заполнен только для шума.
- `summary.csv` - медианы и IQR; `summary_by_group.csv` - медианы по группам.
- Выводы включены в общий `notebooks/EDA.ipynb` и исходный `notebooks/augmentation.ipynb`.
- `recommendations.csv` - отдельная таблица предложений для следующих экспериментов.
- `figures/` - шесть рисунков, также встроенных в ноутбук.

Сигналы остаются в `data/`. Изменённые варианты повторно получаются по исходным данным, seed и параметрам.

Описание методов: [Raghu et al., CHIL 2022](https://proceedings.mlr.press/v174/raghu22a.html). Формат данных и фолды: [PTB-XL v1.0.3](https://physionet.org/content/ptb-xl/1.0.3/). Диапазоны параметров выбраны для этого сравнения.
